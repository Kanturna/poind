# Poind

Poind is a Godot 4.6 territory simulation prototype.

The current direction is colony-level territory expansion on a square grid: colonies place blocks on empty neighboring cells, race for space and resources, and capture enclosed empty regions. The first slices focus on architecture, rules, and deterministic tests before gameplay visuals or learning agents.

## Start Here

- `AGENTS.md` defines the project workflow for future agent work.
- `docs/ARCHITEKTUR.md` defines layer ownership and simulation authority.
- `docs/PLANUNGSAUFTRAG.md` summarizes the current concept, scope, and slice plan.
- `docs/SIM_RULES.md` defines the current territory rules.
- `docs/DECISIONS.md` records architectural and rule decisions.
- `docs/STATUS.md` and `docs/NEXT_STEPS.md` track current state and the next slices.

## Current Status

Slice 0 is documentation and architecture foundation only. No simulation code or lab scene exists yet.
